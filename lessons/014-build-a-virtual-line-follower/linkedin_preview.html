A line follower is a compact lesson in feedback: measure the path, classify the sensor readings, choose a correction, and measure again.

In this Professor OS class, students:

• calibrate a threshold from representative floor and line readings;
• convert ADC counts into binary sensor decisions;
• define deterministic behavior for all three-sensor combinations;
• simulate a curved track and compare robot position with line position;
• investigate starting position, sensor spacing, threshold choice, and noise.

The simulation deliberately avoids pretending to be a complete vehicle model. It uses a direct sideways-position update so learners can isolate the sensing and decision logic before studying wheel dynamics, delay, oscillation, and controller design.

Try the lab by predicting the first steering commands and position updates before running the code. Then change one parameter at a time and compare mean and maximum tracking error.
