A camera image is not a map of the world. It is a projection that compresses 3D geometry into 2D pixels.

This Professor OS lesson uses RoboRover to build an intuitive and mathematical understanding of camera geometry:

• how the pinhole model maps camera-frame coordinates to pixels
• why apparent size decreases with distance
• how focal length and sensor dimensions determine field of view
• how intrinsic parameters differ from extrinsic transformations
• how to test the relationships in a runnable Python simulation

Students also examine calibration, lens distortion, image cropping, coordinate conventions, and the limits of estimating distance from apparent object size. The prediction-first experiment makes the inverse-distance relationship concrete: doubling distance should halve projected height.

Try the lab with a different focal length, marker size, or distance, then compare the prediction with the generated plot. What changes when the camera is resized, cropped, or physically tilted?
