Object detection becomes much easier to reason about when its output is treated as a structured engineering claim rather than a mysterious label.

This Professor OS lesson guides learners from pixels to three core elements:

• where an object appears, using a bounding box;
• what category it may belong to, using a class;
• how strongly the detector supports the result, using confidence.

Students calculate box dimensions and centers, examine image-coordinate conventions, and test threshold trade-offs in a small Python simulation. The lesson also makes an essential distinction: perception proposes evidence, while later behavior logic decides whether a robot should approach, avoid, display, or ignore an object.

Try the lab by changing the confidence threshold and predicting which candidates RoboRover will accept. Then consider how the same detection changes when lighting, motion, occlusion, or processing delay affects the camera stream.
