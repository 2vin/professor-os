A robot that detects an object in one image still does not know whether the next detection belongs to the same object.

This lesson introduces object tracking through a practical one-dimensional RoboRover simulation:

• Predict where an object should appear next using a constant-velocity model.
• Associate new detections with existing tracks.
• Handle missed detections without immediately deleting an object.
• See why crossings, occlusion, and similar objects can cause identity switches.
• Connect image observations to calibrated world coordinates and future mapping.

The Python lab is intentionally small enough to inspect line by line, while still exposing real engineering trade-offs such as greedy matching, gating thresholds, track deletion, and uncertainty.

Try the lab, remove one detection, and predict what the tracker will do before running the code. That simple experiment makes temporal reasoning visible.
