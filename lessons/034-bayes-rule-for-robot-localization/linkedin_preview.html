A sensor reading does not tell a robot exactly where it is. It changes the relative plausibility of possible locations.

This lesson makes that update concrete with a four-cell RoboRover corridor and a noisy blue-beacon sensor. Students:

• distinguish P(z|x) from P(x|z)
• multiply prior belief by sensor likelihood
• normalize scores into a posterior distribution
• test the mathematics with defensive Python code
• investigate strong priors, equal evidence, impossible observations, and dependent measurements

The worked example is deliberately small enough to calculate by hand, while the engineering discussion connects the same logic to motion prediction, calibration, latency, drift, and real localization systems.

Try the lab by changing one prior or likelihood at a time, predicting the result, and then checking whether the code agrees. What evidence would your own sensor produce at each possible state?
