A path on a map is not yet a safe route for a robot.

In Professor OS Class 37, students move from SLAM’s map to the next robotics question: where should the robot drive? They build and validate a grid-based path from a start to a goal while avoiding obstacles.

Students learn to:
• Represent a route as an ordered sequence of positions.
• Verify obstacle avoidance and one-cell movement constraints.
• Calculate planned center-to-center distance.
• Use Python assertions to catch collisions and invalid jumps.
• Recognize why robot width, uncertainty, wheel slip, and changing obstacles matter.

The lesson deliberately separates planning from control: a planner proposes a route, while a controller later turns that route into motor commands. The hands-on lab also shows why checking only listed obstacle cells is insufficient.

Try the lab by designing a second safe route and comparing its length and number of turns with the example. Which route would your robot prefer, and why?
