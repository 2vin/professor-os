A robot cannot plan a route until its environment has been represented in a form a computer can search.

Professor OS Class 38 introduces graph search through a warehouse navigation problem built around RoboRover:

• Model meaningful locations as nodes and possible movements as edges.
• Add costs for distance, time, energy, or risk.
• Compare complete route costs instead of choosing the cheapest immediate move.
• Use a small Python search to enumerate simple routes and verify the best result.
• Examine why sensors must validate a graph that may no longer match the real warehouse.

The lesson combines equations, a worked example, an interactive route-design activity, and executable code. Students also modify the graph by adding a cold-storage area and explore how changing the meaning of cost can change planning decisions.

Try the paper-based RoboRover Route Captain activity, then run the code and predict its output before executing it.
