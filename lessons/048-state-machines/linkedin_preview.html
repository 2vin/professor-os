A trajectory tells a robot how motion should unfold. A state machine decides which behavior should govern the robot right now.

In this Professor OS lesson, RoboRover moves through a docking mission that includes searching, aligning, driving, obstacle stopping, docking, and charging. Students learn to:

• distinguish states, events, guards, and actions;
• represent behavior with diagrams and transition tables;
• connect a measured distance guard to a state transition;
• implement and test a finite-state machine in Python;
• reason about timeouts, unexpected events, and safe-hold behavior.

The lesson also makes an essential systems distinction: a state machine selects behavior, while lower-level controllers execute motion and motor commands. That separation is central to designing robots that are testable and understandable.

Try the paper simulation first, predict the state trace, then run the Python lab and add a low-battery recovery state. What unexpected event would your robot need to handle safely?
