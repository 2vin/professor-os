A robot simulator is more than a moving picture. It is a model that combines a world, geometry, physical rules, collision calculations, and sensor observations.

This Professor OS lesson helps students:

• distinguish visual geometry from collision geometry;
• separate collision detection from collision response;
• calculate when a circular rover reaches an obstacle;
• run and modify a complete Python simulation;
• reason about sensor limits, time steps, tunneling, and the sim-to-real gap.

The central experiment is deliberately modest: RoboRover advances in fixed steps, tests a proposed position against a rectangular obstacle, and reads an ideal forward range sensor. That makes the assumptions visible rather than hiding them inside a simulator.

Try the prediction exercise before running the code. Then change the rover’s height, speed, sensor range, or obstacle layout and explain the result. This is a practical bridge from geometric reasoning to Gazebo-style simulation and, in the next class, reinforcement learning.
