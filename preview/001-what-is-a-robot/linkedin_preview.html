What makes a machine a robot? The answer is more precise than “something autonomous.”

Professor OS Class 1 uses one consistent RoboRover model to establish the foundations students need before studying algorithms and control:

• A teleoperated rover can still be a robot.
• Robot identity is separate from who selects immediate actions.
• Machine and environment boundaries are modeling choices.
• Preprogrammed behavior and feedback can coexist.
• A small Python experiment makes the distinctions observable.

Students compare teleoperation, preprogrammed execution, and task-level autonomy while keeping the same simulated hardware. They predict position traces, run the code, inspect assertions, and modify the controller themselves.

Try the lab by adding a manual reverse mode, then explain whether the robot changed—or only its command sequence did. This is a compact first step toward thinking like a robotics engineer: define the system, identify the boundary, and ask what measurements influence action.
