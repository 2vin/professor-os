A strong robotics foundation begins with a clear question: how does information become motion?

This Professor OS lesson uses RoboRover to make the sense → think → act loop concrete:

• Sensors turn physical conditions into measurements.
• Controllers use goals and measurements to select commands.
• Actuators turn commands into physical effects.
• Feedback connects the changed world back to the next decision.
• A Python simulation lets students test noise, tolerance, overshoot, and speed safely.

The lesson also distinguishes a simple threshold controller from proportional control, introduces units and control error, and makes the limits of simulation explicit. That combination helps beginners build correct mental models before working with physical hardware.

Try the lab: predict how many forward commands RoboRover will issue, run the simulation, then change one parameter and explain the result.
