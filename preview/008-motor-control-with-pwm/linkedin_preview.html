PWM is often introduced as a simple speed knob. That shortcut is useful at first, but it can create persistent misconceptions about voltage, current, torque, and rpm.

This Professor OS lesson uses RoboRover to build the complete signal-chain picture:

• the controller sends a low-power logic command;
• the motor driver switches higher motor current;
• duty cycle describes timing, not guaranteed speed;
• the ideal average-voltage equation is separated from real motor behavior;
• a Python model lets students compare fast switching with slower mechanical response.

The lesson also addresses load, startup friction, current limits, switching frequency, driver topology, noise, and safe observation practices. Students predict results before running the simulation, vary duty cycle and time constant, and distinguish a teaching model from a physical motor law.

Try the lab with 20%, 60%, and 100% duty cycles, then explain which properties change the final model target and which change response time.
