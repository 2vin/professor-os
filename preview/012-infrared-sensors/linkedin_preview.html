A robot’s infrared sensor does not directly measure distance in the way an ultrasonic sensor measures echo time. It measures returned light—and that signal depends on distance, surface reflectivity, angle, lighting, and sensor geometry.

This Professor OS lesson helps students:

• compare reflective IR sensing with ultrasonic time-of-flight;
• understand why a dark and pale object can produce different readings at the same distance;
• use a deliberately simplified model, S = KR/d2, without mistaking it for a universal sensor law;
• choose and test a threshold for a practical robot decision;
• explore calibration and noise with a Python simulation.

The central engineering habit is simple: do not trust a precise-looking sensor number until you have tested what it means in the real environment.

Try the lab by changing reflectivity and threshold, then predict when RoboRover will report CLOSE. What changes when the same threshold is applied to two different surfaces?
