A PID controller is not automatically better because it has three terms. It is better understood when each term is connected to a physical question:

P asks how wrong the robot is now.
I remembers error that persists.
D responds to how quickly that error is changing.

This Professor OS lesson turns those ideas into a discrete-time simulation of a one-dimensional rover. Students inspect individual contributions, actuator saturation, integral windup, noisy derivative estimates, settling time, and the difference between true and measured position.

The hand-calculation activity then separates intuition from implementation, while the real-robot section emphasizes command limits, emergency stops, sensor polarity, and low-gain testing.

Try the lab with the supplied gains, predict the plots first, and then investigate what changes when the target steps or anti-windup is removed.
