A robot camera does not see “orange marker” or “open path.” It records organized numerical measurements, and computer vision begins by learning how to interpret them.

This Professor OS lesson introduces students to:

• Pixels as locations in a rectangular image array
• RGB channels, 8-bit values, and normalization from 0–255 to 0–1
• Width, height, channels, and row-column indexing
• A complete Python lab using nested RGB lists and Matplotlib
• Why lighting, exposure, shadows, and noise make vision measurements uncertain

The RoboRover activities make the abstraction concrete: students predict how changing one channel changes a pixel and the image average, then experiment with a small simulated scene. The lesson ends by connecting pixel evidence to the next class on thresholding and segmentation.

Try the Pixel Detective lab, then ask: what evidence would make a color-based decision unreliable?
